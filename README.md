# ERSACTZ — Season 01

Интерактивный сайт для РК1 по Twitch-каналу [ersactz](https://www.twitch.tv/ersactz/about).

Данные: 10 индивидуальных карточек трансляций и два 30-дневных отчёта Twitch Analytics, предоставленных автором. Показатели разных отчётов подписаны отдельно; просмотры эфиров не приравниваются к уникальным зрителям.

Сайт статический: `index.html`, `styles.css`, `script.js` и локальные файлы в `assets/`. Для локального просмотра запустите HTTP-сервер в корне репозитория, например `python -m http.server 4173`.

В оформлении использованы аватар автора и кадр фильма *Ted* (© Universal Pictures) как визуальный материал учебного проекта. Два игровых MP4-файла предоставлены автором канала.
